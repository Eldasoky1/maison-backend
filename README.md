# Maison Backend

Public backend repository for Maison: the PostgreSQL schema, Supabase migrations,
seed data, Row Level Security policies, storage policies, scheduled retention,
and Deno Edge Functions used by the AI advisor.

## What is included

- `supabase/migrations/` — ordered PostgreSQL 15 migrations.
- `supabase/seed.sql` — reference data, demo personas, and synthetic residences.
- `supabase/functions/` — `chat-respond`, `embed-property`, and `tag-property-images`.
- `supabase/tests/` — database and Edge Function tests.
- `supabase/config.toml` — local Supabase configuration.
- `.env.example` — variable names only; no secrets are committed.

## Local setup

Requirements: Node.js 20+, Supabase CLI, and Docker Desktop or Podman.

```bash
npm install
cp .env.example .env.local
npx supabase start
npm run db:reset
npm run db:test
npm run test:integrity
```

The local Supabase stack uses the configuration in `supabase/config.toml`.
The seed file creates the reference catalog, 30 synthetic listings, agent and
client personas, and the demo relationships used by the frontend.

## Supabase project setup

Link this repository to a Supabase project, then push migrations:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npm run db:push
```

Never commit `SUPABASE_SERVICE_ROLE_KEY`, database passwords, OpenRouter keys,
or other credentials. Use Supabase project secrets for Edge Functions:

```bash
npx supabase secrets set OPENROUTER_API_KEY=...
npx supabase secrets set CHAT_MODEL=anthropic/claude-sonnet-4.5
npx supabase secrets set EXTRACTION_MODEL=anthropic/claude-haiku-4.5
npx supabase secrets set EMBEDDING_MODEL=openai/text-embedding-3-small
npx supabase secrets set VISION_MODEL=google/gemini-2.5-flash
npx supabase secrets set FALLBACK_MODELS=openai/gpt-4.1-mini,google/gemini-2.5-flash
npx supabase secrets set DAILY_SPEND_CAP_USD=2.00
```

## Google AI Studio handoff

Use the public GitHub repository as the backend source for Google AI Studio.
The browser/client application should use only the Supabase publishable or
anonymous key. Service-role credentials belong only in server-side jobs and
Supabase secrets. RLS is enabled across the public schema, so frontend access
must follow the policies in `supabase/migrations/20261027000900_rls.sql`.

The AI advisor can call the `chat-respond` Edge Function. Property embeddings
are generated by `embed-property`, and image-based style/amenity tagging is
handled by `tag-property-images`.
